JAINEX KITCHENWARE — WEBSITE FILES

1. Extract this ZIP file.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Double-click index.html to preview the website.
4. The WhatsApp number is already configured in script.js as 919983366368.
5. Product names and prices are samples. Edit the products list in script.js before publishing.
6. For free publishing, sign in to a static host such as Netlify and upload the extracted folder containing index.html. Follow the host's current instructions.

IMPORTANT: This starter site provides product enquiries via WhatsApp. It does not yet include a real cart, online payment gateway, inventory database, customer accounts, or automatic shipping/tracking. Product prices shown are examples.
