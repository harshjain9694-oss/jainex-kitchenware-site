JAINEX KITCHENWARE — नए प्रोडक्ट फोटो

इस ZIP में आपके भेजे हुए 10 प्रोडक्ट फोटो assets/products/catalogue-photos/ फोल्डर में रखे हैं। चार slider banners assets/banners/ में पहले से शामिल हैं।

जरूरी: अभी फोटो फाइलें वेबसाइट प्रोजेक्ट में जोड़ दी गई हैं, लेकिन जिन प्रोडक्ट्स की सही कीमत/नाम/कैटेगरी पक्की नहीं है, उन्हें अपने-आप लाइव प्रोडक्ट लिस्ट में नहीं डाला गया है। इससे गलत कीमत या गलत प्रोडक्ट जानकारी नहीं दिखेगी।

पहले टेस्ट करें:
1. ZIP को Extract All करें।
2. VS Code में अंदर वाला jainex-kitchenware-site-main फोल्डर खोलें।
3. ऊपर Restricted Mode आए तो केवल तभी Trust Folder & Continue दबाएँ जब आपने यह ZIP इसी बातचीत से डाउनलोड की हो।
4. Extensions में Live Server पर Enable (Workspace) दबाएँ।
5. Explorer में index.html पर right-click करके Open with Live Server चुनें।

Admin panel: admin.html खोलें। वेबसाइट अभी static JSON पर आधारित है; यह कोई सुरक्षित online database वाला full CMS नहीं है। Admin में किए बदलाव इस demo/local setup में ही रह सकते हैं और browser refresh/hosting के हिसाब से persist होने की गारंटी नहीं है। Live website पर बदलने से पहले लोकल टेस्ट करें।
