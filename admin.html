Edit name, category, price, image path, description and visibility. For a new photo, first copy the image into assets/products, then enter its relative path.

How to publish

  1. Save your changes here and check the local website in this same browser.
  2. Click Export site.json and Export products.json.
  3. Replace the matching files in your project’s data folder with the exported files.
  4. Test again; only then upload/commit the project to GitHub so Netlify can deploy it.

For a production admin panel that updates the public site securely from any device, use Pages CMS connected to your GitHub repository or add a server/database backend. This local editor is not password-secured.
